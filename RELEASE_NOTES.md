# Rugby Referee Review v2.0.6

## 🎉 Personal Setup & Auto-Fill

This release introduces a **personalized onboarding experience** that makes the app truly yours!

### What's New:
- ✅ **First-run welcome screen** - Set up your info once, never type it again
- ✅ **Auto-fill your name** in every review automatically
- ✅ **Auto-fill coach name** in every review
- ✅ **Settings menu** to update your info anytime
- ✅ **Game grade dropdown** for consistent data entry
- ✅ **Improved dialog layouts** with better button styling

### Also Includes (from previous releases):
- 📊 **Analytics Dashboard** - View performance trends and statistics
- 📂 **Review History** - Browse, search, and load past reviews
- 💾 **Auto-save** - Every review saved as JSON automatically
- 🎨 **Professional UI** - Splash screen, menu bar, polished design

## 📥 Download for Your Platform:
- **Windows:** `rugby-referee-review-windows.zip`
- **macOS:** `rugby-referee-review-macos.zip`
- **Linux:** `rugby-referee-review-linux.tar.gz`

## 🚀 Quick Start:
1. Download and extract for your platform
2. Run the application
3. Complete the welcome screen (first time only)
4. Start creating reviews!

## ⚠️ Windows Users:
Windows may show "Unknown Publisher" warning. Click "More info" → "Run anyway". The app is safe - this is normal for open-source software without a code signing certificate.
