# Rugby Referee Review System v2.1.1-alpha3

## 🌍 Multi-Region Support + UI Fixes

Alpha Release 3 adds regional grade customization and fixes critical UI issues!

### ✨ What's New:

**🌍 Regional Grades**
- Select region on first run (Otago, Southland, South Canterbury)
- Each region shows specific game grades
- Change region anytime in Settings
- Easy to add more regions

**🐛 Bug Fixes**
- Fixed dropdown jumping on metadata page
- Fixed Personal Info settings window height
- Improved overall UI stability

### Regions Supported:
- **Otago:** 13 grades
- **Southland:** 8 grades  
- **South Canterbury:** 5 grades

### Also Includes:
- ✅ IDP with Word export
- ✅ Keyboard navigation (Tab/Enter)
- ✅ CRRDF reviews & GFA tracking
- ✅ Analytics dashboard
- ✅ All Alpha 2 features
